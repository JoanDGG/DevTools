# Pixel Play DevTools

Unity project for developing and validating reusable Pixel Play systems.

The embedded **Pixel Play Foundation** UPM package lives at [`Packages/com.pixelplay.foundation`](Packages/com.pixelplay.foundation/README.md). Unity automatically loads packages placed in the project's `Packages` folder.

To use the package in another Unity project, add this Git URL in Package Manager:

```text
https://github.com/JoanDGG/DevTools.git?path=/Packages/com.pixelplay.foundation
```
